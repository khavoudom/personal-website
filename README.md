# personal-website

Hey, welcome to my digital notebook. 👋

I'm a CS student at the University of Cambodia who loves building things for the web — from interactive frontends with React and Vue to APIs and databases on the backend. This portfolio is where I write down what I'm working on, what I've learned, and what I'm curious about next.

The notebook theme isn't just for looks — it reminds me that everything is a work in progress. Ideas get scribbled, revised, and sometimes coffee-stained along the way.

## What's inside

- Projects I've built
- Skills I'm actively using
- Ways to get in touch

## Built with

- **Next.js 16** (App Router)
- **Tailwind CSS v4**
- **Caveat** + **Special Elite** fonts

## Running locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and take a look around.
